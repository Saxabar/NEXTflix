# Changelog

## 1.1 (2026-10-25)

- The menu starts on the last game you started (kept in `LAST.TXT` in the menu folder), with the
  favourites shown if they were.
- SYMBOL SHIFT + ENTER starts a tape or snapshot asking again how to start it (128K, 48K, ...), as
  in the NextZXOS Browser.
- NEXTflix-Prepare remembers the folders also when you close it.
- NEXTflix-Prepare no longer copies all the games again after a change of daylight saving time.
- The menu reads `GAMES.IDX` with any line ends (CR, CR LF, LF), e.g. written on a Mac or on Linux.
- `NEXTflix-1.1-next.zip`: only the files of the menu, to set it up without NEXTflix-Prepare (see
  the README).
